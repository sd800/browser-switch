A FEW GOOD QUESTIONS

Small app.
Simple answers.

Is Browser Switch another web browser?

It registers as your default browser so macOS can send it links, then passes them to an installed browser. It doesn’t display web pages or replace the browsers you already use.

Which browsers work with it?

Browser Switch discovers installed browsers through the macOS application registry, including Chrome, Firefox, Safari, and Microsoft Edge. You can hide options and customize their order in Settings.

Can I match just one exact domain?

Yes. Domains added inline include subdomains. To match only an exact hostname, open the Domains page, press Command-N, and turn off Include subdomains before adding it.

Does it remember the browser I pick?

Each choice is for the current link. The next matching link asks again. Links outside your domain list continue to use the default browser you set.

Does it need to stay in my Dock?

No. The menu bar and persistent Dock icons can be turned on or off independently. With both off, reopen settings from Spotlight or Applications. macOS can launch Browser Switch when a link needs it.

First time opening the app?

The current download is ad hoc signed and hasn’t been notarized by Apple. If macOS blocks it on first launch:

Open System Settings → Privacy & Security. Scroll to Security, click Open Anyway beside Browser Switch, then confirm Open.
